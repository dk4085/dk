Auth сервис - Python JWT сервис аутентификации

Это сервис аутентификации и авторизации на основе FastAPI, использующий JWT-токены для аутентификации пользователей.

Функциональные возможности

Регистрация пользователя (email и пароль)

Вход пользователя (возвращает access и refresh JWT-токены)

Обновление access-токена с помощью refresh-токена

Обновление информации пользователя (email и пароль)

Просмотр истории входов

Выход пользователя (добавление токена в черный список)

Технологический стек

Python 3.9

FastAPI - веб-фреймворк

PostgreSQL - база данных

Redis - хранилище токенов в черном списке

Docker & Docker Compose - контейнеризация и развертывание

JWT (JSON Web Tokens) - аутентификация

API эндпоинты

1. Регистрация пользователя
Метод: POST
Эндпоинт: /register
Описание: Создание нового пользователя
Тело запроса:

json
{
  "email": "example@example.com",
  "password": "securepassword"
